# Image/Gif/Schematic > Command Block Converter
https://piggopotamus.github.io

Convert schematics, images and GIFs into items for Minecraft Java Edition.
Schematic items run /fill commands, and GIFs/images are converted into text
displays with colored characters for each pixel.
Conversion happens in your browser; your files are not uploaded.
Validated to work in `1.21.11` - `26.3`. Other versions may work, but they're
untested.

AI disclaimer: The website is made entirely via AI, however the command
blocks were mostly human- there were prompts to optimize my handmade versions
and assemble the command blocks into a single chunk.
