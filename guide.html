User guide

Turn schematics, images, GIFs and videos into items for Minecraft Java Edition. Everything runs in your browser, so your files never get uploaded anywhere.

Images and GIFs

  1. Grab the MID engine item from the Images/GIFs page and place it in creative mode. Command blocks need to be enabled.
  2. Pick your image, GIF or video, tweak the settings if you want, and hit Convert.
  3. Flip between Source and Converted to check it looks right, then copy or download the item.
  4. Place the item in your world. Run /trigger mid next to it to change its size, speed, rotation and more.

If something is still loading, /trigger mid shows how far along it is and lets you cancel it.

You can change Width in blocks, Billboard, Black backing and the item name after converting without waiting for it to convert again.

The defaults (1000 KB, 16,000 pixels per frame, 75 frames, Medium quality) work well for most things. You can push it to around 2076 KB and 20,000 pixels, but bigger items take longer to load, can lower your FPS, and some servers won't accept them.

Ticks per frame sets how long each frame stays on screen. If a clip has more frames than the frame cap, frames get skipped evenly, so the GIF plays through faster.

Placing the same image again reuses what was already loaded, so copies show up almost straight away. This uses a little extra world storage. To clear it, wait until nothing is loading and run /data remove storage mid:media m. Your existing displays keep working.

Schematics

Choose a .schem, .litematic or .schematic file and convert it. Place the item to see a preview outline, then use its menu to build. You don't need MID for schematics.

Each schematic item builds itself; nothing else needs installing. Items are kept small enough that taking one never disconnects you, so a very big schematic gets split into a few items. Place them all, in any order. Each one loads and disappears, and the last one opens the preview, so place that one where you want the schematic.

Optimisation effort picks how hard the converter looks for fewer commands. Thorough, the default, copies repeated parts of the build, which helps a lot with rows of identical rooms or patterns. Max searches longer, and Balanced and Fast are quicker. If the space for the build holds only air, turn on Build area is empty to make copying work even better. Turn on Remove block data to leave out chest contents, sign text and similar data.

Getting your items into the game

  • SNBT: import it with the Item Editor mod (by noramibu) in creative mode. This is the easiest way.
  • .give: paste it as a Meteor Client command.
  • /give: usually too long for chat or a command block, so put it in a datapack function instead.
  • Datapack: type your Minecraft username, then drop the ZIP (don't unzip it) into your world's datapacks folder and run /reload. You'll get the items once.

Works on Java 1.21.11, 26.2 and 26.3, on vanilla and Paper.
